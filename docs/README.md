# Documentation map

Where to start, and which files a human may edit by hand. Three kinds of document live here, and
the kind decides how a change lands:

- **Hand-written** — edit in a PR like any other file.
- **Generated** — never edit; change the source and regenerate (the `*:check` npm script for each
  one is a CI gate, so a stale copy fails the PR).
- **Parsed by a gate** — hand-written, but a test or a gate reads its structure, so a heading or
  a verb table is load-bearing; the file says so at its top.

## Outside `docs/`

- `MASTER-PLAN.md` — the design and the plan; carries a machine-owned CAPABILITY SNAPSHOT block
  and is indexed by `plan/plan-index.json`.
- `DECISIONS.md` — the append-only decision log; `src/lib/review.ts` enforces a provenance mark on
  every added entry.
- `LEARNINGS.md` and `learnings/*.yaml` — the machine-readable, budget-ratcheted learnings store.
- `CLAUDE.md` — workflow rules injected into every agent session, held under a byte budget
  (`scripts/claude-md-budget-ratchet.mjs`): a new rule must displace an old one.
- `FINDINGS.md`, `DIAGNOSIS.md` — dated snapshots from WS-0 and the first triage pass; read as
  history, not as current state.
