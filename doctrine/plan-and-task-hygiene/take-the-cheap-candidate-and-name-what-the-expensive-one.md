- **Take the cheap candidate a record prices beside a costly one — and name what the costly one
  now waits for.** SEVEN of the eleven shards ruled on 2026-09-22 had
  exactly this shape, and in every one the cheap candidate was the right answer for a reason the
  record had already measured and then failed to act on. W1-T1014 offered a GitHub flag the operator
  already owns beside re-running CI on every open PR at 239 CI-hours/day — and the expensive half
  only DETECTS, so the blast radius survives the spend. W1-T2445 offered printing a reason map
  `planBranchReap` already computes beside a first-ever branch deletion path over a set nobody has
  reviewed by name. W1-T3041 offered one observation that separates two candidate causes beside a
  fix for whichever cause you guessed — with even odds of patching the wrong subsystem, which is
  this repo's recurring defect. **THE HALF THAT MAKES THIS A RULE RATHER THAN TIMIDITY IS THE
  SECOND CLAUSE.** Taking the cheap candidate without saying what would re-open the expensive one
  turns a decision into an omission, and the expensive candidate comes back next cycle with the
  same argument and no new evidence. So each ruling names its trigger: W1-T3103 defers removing the
  network namespace UNTIL someone counts the implement turns that touch the network; W1-T2445 makes
  its own named report the review a deletion path needs and does not have; W1-T1014 states the
  throughput ceiling it is accepting so nobody re-litigates it as a surprise. A cheap candidate
  chosen with a stated trigger is a decision; chosen without one it is a deferral wearing a ruling's
  clothes. **AND THE CHEAP CANDIDATE IS NOT ALWAYS THE SMALL ONE.** W1-T3056's cheap-looking ending
  was DELETING an unwired predicate; the ruling took the costlier wiring, because it replaces an
  LLM inference with set arithmetic and this repo's doctrine prefers a computed fact to an inferred
  one everywhere else. Cheap means *low-risk and reversible*, not *fewest lines*. *(#6560 — eleven
  parked rulings, seven of them this shape)*
